# UrbanHub

UrbanHub is an urban digital twin project, that aims to collect, analyze, and utilize IoT data from a modern city. It is designed to simulate a real-world like Smart City environment.

## Design

Design documentation is availlable in the [docs/1_design](./docs/1_design) folder.

## Convention and tools

- When working on Markdown files, use [Mermaid](https://mermaid.ai/open-source) codeblocks to add diagrams if possible. Use only Mermaid v11 syntax (supported by VSCode and GitHub).
- If Mermaid is too limited, diagrams should be created with [draw.io](https://www.drawio.com) and included in the project as `.drawio.svg` files. Let the user create the diagrams unless you have direct capabilities to create them.
